# pydudi
The objective of this module is to propose an implementation of data analysis methods based on duality diagram in python (and Rcpp) and to develop and expand my skill in python (and Rcpp). The Python package containing the functions pyDudi, pyPCA, ..., is available at the following link: [package directory](https://github.com/badozor/pydudi/tree/main/trunk/package/dist).
